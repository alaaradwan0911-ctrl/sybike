# Sybike Premium visual update

This is a visual-only stylesheet. It does not change JavaScript, Firebase, authentication, Firestore rules, IDs, or page routing.

## Install
1. Upload `premium.css` to the repository root next to `index.html`.
2. In each of these files — `index.html`, `restaurant.html`, `driver.html`, and `admin.html` — add this line immediately before `</head>`:
   `<link rel="stylesheet" href="premium.css">`
3. Commit and wait for GitHub Pages to publish.
4. Refresh the app. If the old style remains, clear the browser cache or open the page in a private tab.

Keep the original `<style>` blocks and all scripts unchanged. This stylesheet overrides the appearance only.
